📦 新功能：自定义解包完成提示
------------------------------------------------

1. 打包时的新功能：
   - 在打包界面有一个"解包完成提示"文本框
   - 可以输入自定义消息，例如：
     * Discord 服务器邀请链接
     * 联系方式
     * 使用说明
     * 感谢信息
   - 支持多行文本
   - 支持 HTTP/HTTPS 链接（会自动识别并可点击）
   - 留空则只显示"解包成功"

2. 解包时的效果：
   - 解包完成后会弹出对话框
   - 显示"解包成功！"标题
   - 显示你设置的自定义消息
   - 消息中的链接可以直接点击打开
   - 如果没有设置消息，只显示简单的成功提示

🚀 使用步骤
------------------------------------------------

方式一：直接使用 EXE（推荐）
1. 双击 comfy-pack-unpack.exe
2. 选择压缩包（.cpack.zip）
3. 选择 ComfyUI 目录
4. 自动检测 Python 和 Git
   - 优先从 ComfyUI 同级目录检测（如 python/, git/）
   - 如果检测失败，可以手动选择
5. 点击"开始解包"

📁 推荐目录结构：
ComfyUI-aki-v2/
├── ComfyUI/      ← 选择这个目录
├── git/          ← 自动检测
├── python/       ← 自动检测
└── 其他文件...

方式二：开发测试（无需打包）
1. cd exe
2. python run_dev.py

⚠️ 注意事项
------------------------------------------------

1. Python 和 Git 必须可用
   - 工具会优先从 ComfyUI 同级目录查找
   - 支持便携式版本（不需要全局安装）
   - 如果检测失败，可以手动选择路径

2. 需要网络连接（下载插件和依赖）

3. 确保选择的是 ComfyUI 根目录（包含 main.py 的目录）

4. 自定义消息会保存在压缩包中的 completion_message.txt

5. 推荐目录结构（与 SD-Launcher 兼容）：
   父目录/
   ├── ComfyUI/
   ├── git/
   └── python/

🐛 常见问题
------------------------------------------------

Q: 检测不到 Python 环境？
A: 
- 确保选择的是 ComfyUI 根目录
- 工具会按顺序查找：
  1. ComfyUI 同级的 python/ 目录
  2. ComfyUI 内部的 .venv 或 venv
  3. 全局 Python
- 如果都没有，点击"手动选择"指定路径

Q: 检测不到 Git？
A:
- 工具会按顺序查找：
  1. ComfyUI 同级的 git/ 目录
  2. 全局 Git 安装
- 如果都没有，点击"手动选择"指定 git.exe 路径
- 便携式 Git: 选择 git/bin/git.exe 或 git/cmd/git.exe

Q: 插件安装失败？
A: 检查网络连接和 Git 是否可用

Q: 链接无法点击？
A: 确保链接以 http:// 或 https:// 开头
